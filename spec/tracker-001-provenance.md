# Tracker provenance

The tracker in `src/radar_forge/core/tracking/` comes from `unified-extensible-tracker`, an
earlier tracker written by Ng Zeming Michael Eugene, the author of this port. He contributes it
to radar-forge under the repository's MIT licence ([`LICENSE`](../LICENSE)).

Where the code implements a published method, the module or class docstring cites the source in
its `References` section.
